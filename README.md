# Ad Campaign Designer Team

A multi-agent AI application that helps you create compelling ad campaigns through guided storytelling and prompt generation.

## Overview

This application uses two specialized AI agents working together:

1. **Ad Creative Agent** - Interviews you about your product/service and creates a storytelling scene blueprint
2. **Prompt Generator Agent** - Transforms scenes into image generation prompts and scripts

## Features

- Interactive discovery interview to understand your product
- Automated scene blueprint generation with story arc
- AI image prompts optimized for DALL-E, Midjourney, and Stable Diffusion
- Professional ad scripts and copy
- Export to markdown files for easy use

## Installation

```bash
# Clone the repository
git clone https://github.com/aulgen/aulgen.git
cd aulgen

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

## Configuration

Set your Anthropic API key:

```bash
export ANTHROPIC_API_KEY='your-api-key-here'
```

Or create a `.env` file:

```
ANTHROPIC_API_KEY=your-api-key-here
```

## Usage

Run the application:

```bash
python main.py
```

The application will:
1. Welcome you and explain the process
2. Ask discovery questions about your product/service
3. Generate a scene blueprint for your ad campaign
4. Create image prompts and scripts for each scene
5. Save all assets to the `output/` folder

## Output Files

After running, you'll find these files in `output/<campaign_name>/`:

| File | Description |
|------|-------------|
| `image_prompts.md` | Ready-to-use prompts for AI image generators |
| `campaign_script.md` | Complete script with all scenes |
| `scene_blueprint.md` | Story arc and scene breakdown |
| `campaign_summary.md` | Executive summary |
| `campaign_data.json` | Raw data for programmatic use |

## Example Workflow

1. **Run the app**: `python main.py`

2. **Answer questions** about your product:
   - What is your product/service?
   - Who is your target audience?
   - What are the key benefits?
   - What emotional tone do you want?

3. **Review the scene blueprint** generated by the Ad Creative Agent

4. **Get your assets**:
   - Image prompts for AI image generation
   - Scripts for voiceover or text overlays

5. **Create your ad**:
   - Generate images using the prompts
   - Record voiceover from the scripts
   - Assemble in your video editor
